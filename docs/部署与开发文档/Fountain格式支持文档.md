## **1. Fountain格式概述**

Fountain是一种免费、开源的纯文本标记语言，专门用于编剧。它让编剧可以在任何纯文本编辑器中写作，然后由兼容软件自动转换成专业剧本格式。

### **1.1 核心优势**

- **纯文本格式**：可在任何编辑器中编辑
- **版本控制友好**：适合Git等版本控制系统
- **行业标准**：与Final Draft、Highland等专业软件兼容
- **轻量级**：文件体积小，传输方便

### **1.2 官方资源**

- **官网**：http://fountain.io/
- **语法规范**：http://fountain.io/syntax
- **示例文件**：http://fountain.io/samples

## **2. Fountain语法规范**

### **2.1 核心元素类型**

| 元素类型 | 识别规则 | 示例 | 格式化效果 |
| :---- | :---- | :---- | :---- |
| **场景标题 (Scene Heading)** | 以INT./EXT.开头，全大写 | `INT. COFFEE SHOP - DAY` | 顶头、大写、加粗 |
| **动作/描述 (Action)** | 不符合其他规则的文字 | `小明不安地看着门外。` | 顶头、正常字体 |
| **角色名 (Character)** | 全大写，前后有空行 | `LI HUA` | 居中、大写 |
| **对话 (Dialogue)** | 紧跟在角色名下方 | `今天我们能完成这个剧本吗？` | 居中，有左右边距 |
| **括号台词 (Parenthetical)** | 用()包裹，在角色名和对话间 | `(轻声地)` | 居中，比对话稍窄 |
| **过渡 (Transition)** | 以>开头或全大写TO:结尾 | `>FADE OUT` | 靠右对齐、大写 |
| **注释 (Notes)** | 用[[]]包裹 | `[[这里需要一个笑话]]` | 导出时忽略 |

### **2.2 强制元素标记**

| 标记 | 用途 | 示例 |
| :---- | :---- | :---- |
| `.` | 强制场景标题 | `.FLASHBACK - HOSPITAL - NIGHT` |
| `@` | 强制动作 | `@小明内心独白` |
| `#` | 强制角色名 | `#NARRATOR` |

### **2.3 特殊语法**

```fountain
# 标题页
Title: 我的剧本
Credit: 编剧：张三
Author: 张三
Draft date: 2024-12-19
Contact: zhangsan@email.com

# 场景标题
INT. COFFEE SHOP - DAY

# 动作描述
小明不安地看着门外，手里紧握着咖啡杯。

# 角色和对话
LI HUA
今天我们能完成这个剧本吗？

XIAO MING
(轻声地)
应该可以，我们还有时间。

# 过渡
>FADE OUT

# 注释（导出时忽略）
[[这里需要一个更紧张的场景]]
```

## **3. ScriptWriter中的Fountain实现**

### **3.1 解析器架构**

```
Fountain文本 → 词法分析器 → 语法分析器 → AST → 格式化器 → 渲染输出
```

### **3.2 核心解析功能**

| 功能模块 | 描述 | 实现方式 |
| :---- | :---- | :---- |
| **词法分析** | 将文本分解为Token | Rust正则表达式 |
| **语法分析** | 构建抽象语法树 | 递归下降解析器 |
| **元素识别** | 自动识别元素类型 | 基于规则的分类器 |
| **格式化** | 生成渲染输出 | HTML/CSS模板 |

### **3.3 实时预览功能**

- **增量解析**：只解析变更的部分
- **语法高亮**：不同元素类型使用不同颜色
- **错误提示**：实时显示格式错误
- **自动补全**：智能提示角色名和场景标题

## **4. 导入导出功能**

### **4.1 支持的格式**

## **5. 错误处理与验证**

### **5.1 常见错误类型**

| 错误类型 | 描述 | 解决方案 |
| :---- | :---- | :---- |
| **格式错误** | 不符合Fountain语法 | 提供修正建议 |
| **编码错误** | 文件编码不支持 | 自动转换编码 |
| **结构错误** | 元素嵌套不正确 | 重新解析结构 |

### **5.2 验证规则**

- **场景标题**：必须包含INT./EXT.和地点
- **角色名**：不能包含特殊字符
- **对话**：必须跟在角色名后面
- **括号台词**：必须用()包裹

## **6. 性能优化**

### **6.1 大文件处理**

- **流式解析**：逐行处理，避免内存溢出
- **增量更新**：只重新解析变更部分
- **缓存机制**：缓存解析结果，提高响应速度

### **6.2 内存管理**

- **对象池**：重用解析器对象
- **垃圾回收**：及时释放不需要的数据
- **内存映射**：大文件使用内存映射读取
